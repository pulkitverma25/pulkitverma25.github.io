<h5>This work was done at <a href="http://www.iitg.ac.in/cse/robotics/" target="_blank">Robotics Lab, IIT Guwahati</a>.</h5>

The aim of this work is to enable the robots to perform sequential tasks by cooperating with each other via stigmergic communication. Mobile Agents are used for implementing stigmergy and to make the system decentralized. To test the feasibilty of the system, a task is subdivided into a set of 5 sequential tasks. 5 mobile agents are released in the mobile agent system where the execute themselves on 3 robots. <a href="http://mindstorms.lego.com/">LEGO NXT Mindstorms</a> bricks, <a href="http://www.iitg.ernet.in/cse/robotics/?page_id=477">Typhon</a> and <a href="http://www.iitg.ernet.in/cse/robotics/?page_id=477">LEGO NXT Interface for Prolog</a> were used in the experiments.
